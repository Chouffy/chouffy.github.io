Is a [[wireless]] [[network]] protocol used notably in [[phone]]
## Acronyms
- RSRP: Reference Signal Received Power
	- Better indicator of signal strength
	- 0dBm (best signal) to -110dBm (weakest/no signal)
- RSSI: Received Signal Strength Indicator
	- 0dBm (best signal) to -110dBm (weakest/no signal)
- RSRQ: Reference Signal Received Quality
	- Connection reliability
	- 0dB (highest quality) to -20dB (lowest quality)
