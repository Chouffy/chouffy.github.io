## Icons
### Bus speed
- Ultra-High Speed (UHS) Class – represented by a “U” symbol
	- Bus
		- UHS-I: theoretical maximum read/transfer ≤ 104MB/s
		- UHS-II: theoretical maximum read/transfer ≤ 312MB/s
			- Contains 2nd row of pins
		-  UHS-II: theoretical maximum read/transfer ≤ 624MB/s
	- Minimum speed: see below table
- SD Express Speed Class – represented by an “E” or "EX" logo, uses [[PCI Express|PCIe]]
	- *EX I* is the bus speed
	- Also uses the 2nd row of pins; but not backward compatible with UHS-II, only UHS-I
