Is a [[Software]] for the [[Raspberry Pi Pico|Pi Pico]] and other to emulate gamepads from [[PlayStation 3|PS3]], [[Nintendo Switch|Switch]], etc using other gamepads/inputs
## Notes
- [Original repo](https://github.com/wiredopposite/OGX-Mini) or [this active fork](https://github.com/MegaCadeDev/OGX-Mini-2026) 
- [Pairing instructions](https://bluepad32.readthedocs.io/en/latest/supported_gamepads/)
### Web App
- [Link](https://megacadedev.github.io/OGX-Mini-2026-WebApp/)
- Need to press Start + Left Bumper + Right Bumper for 3 seconds.
	- If doesn't work, try to press Start, then left, then right (space ≈ 100 ms)
	- For [[PlayStation 4]] controller: Options + L1 + R1
